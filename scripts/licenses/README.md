# Supplemental license texts

Some npm tarballs omit their repository license files. These copies are used
only for the named packages in `scripts/bundle.mjs`. Review them when those
packages change licenses. Builds do not download license files.

- [puppeteer-LICENSE](https://raw.githubusercontent.com/puppeteer/puppeteer/a207faf527ce4305b33a6c0f9706b090c21c115e/LICENSE)
- [aws-sdk-LICENSE](https://raw.githubusercontent.com/aws/aws-sdk-js-v3/a30774464d92378573136c00ca5dd523f82d5939/LICENSE)
- [proxy-agents-LICENSE](https://raw.githubusercontent.com/TooTallNate/proxy-agents/84e41e433b422cbe9f073952d8e16052eb9b0251/packages/https-proxy-agent/LICENSE)

`proxy-agent-negotiate` declares MIT and Nathan Rajlich as its author but ships
no license file. The MIT text above is from the same author’s proxy-agents
repository (`https-proxy-agent`).
